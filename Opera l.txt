### Practical 8: Transportation Problem

Aim:

* To find an initial basic feasible solution using North-West Corner, Least Cost and Vogel's Approximation Methods.

* To obtain the optimum transportation schedule using the MODI (u–v) Method.

Tools: Transportation table / calculator / Excel.

Steps to perform:

* Prepare the transportation cost matrix.

* Enter the supply values and demand values.

* Calculate total supply and total demand.

* Check whether the transportation problem is balanced.

* If unbalanced, add a dummy row or column.

* Apply the North-West Corner Method:

    * Start from the top-left cell.

    * Allocate the minimum of available supply and demand.

    * Adjust the remaining supply and demand.

    * Move right or down as required.

* Apply the Least Cost Method:

    * Find the cell with the lowest transportation cost.

    * Allocate the maximum possible quantity.

    * Update supply and demand.

    * Repeat until all are satisfied.

* Apply Vogel's Approximation Method:

    * Calculate row and column penalties.

    * Select the row or column with the highest penalty.

    * Allocate to the lowest-cost cell in it.

    * Update supply and demand.

    * Recalculate penalties and repeat.

### Practical 9: Assignment Problem – Minimization

Aim:

* To assign workers to jobs on a one-to-one basis.

* To minimise the total assignment cost or time.

* To solve the assignment problem using the Hungarian Method.

Tools: Assignment matrix / calculator / Excel.

Steps to perform:

* Prepare the given assignment cost matrix.

* Check whether the matrix is square.

* If it is not square, add a dummy row or column with zero cost.

* Perform row reduction:

    * Find the smallest element in each row.

    * Subtract it from every element in that row.

* Perform column reduction:

    * Find the smallest element in each column.

    * Subtract it from every element in that column.

* Cover all zeros using the minimum number of horizontal and vertical lines.

* Count the number of lines.

* If the number of lines equals the order of the matrix, proceed to assignment.

* If the number of lines is less than the order:

    * Find the smallest uncovered element.

    * Subtract it from all uncovered elements.

    * Add it to elements at the intersections of lines.

    * Leave the remaining elements unchanged.

* Repeat the zero-covering and adjustment process.

* Make one-to-one assignments using independent zeros.

* Calculate the total minimum cost using the original cost matrix.

Step example – Hungarian Method format:

Suppose the assignment matrix has four workers and four jobs. Arrange it as:

| Worker / Job | J1   | J2   | J3   | J4   |
| ------------ | ---- | ---- | ---- | ---- |
| W1           | Cost | Cost | Cost | Cost |
| W2           | Cost | Cost | Cost | Cost |
| W3           | Cost | Cost | Cost | Cost |
| W4           | Cost | Cost | Cost | Cost |

Then perform row reduction, column reduction, zero covering and assignment. Use the original matrix to calculate the total cost.

No separate programming code is required.
